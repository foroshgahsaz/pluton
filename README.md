# پلوتون — فروش اکانت آمار بازدید ماتومو

صفحه معرفی برای فروش اکانت آماده ماتومو. اسکریپت روی هاست پلوتون نصب می‌شود و مشتری فقط پنل و کد رهگیری می‌گیرد.

## پنل‌ها

فرض تجاری این صفحه، تا وقتی قیمت و سقف واقعی را جایگزین کنید:

| | نقره‌ای | طلایی |
|---|---|---|
| وب‌سایت | ۱ | ۵ |
| بازدید صفحه در ماه | ۵۰ هزار | ۵۰۰ هزار |
| نگهداری داده | ۱۲ ماه | ۲۴ ماه |
| کاربر پنل | ۱ | ۵ |
| هدف تبدیل | تا ۵ | نامحدود |
| ردیابی فروش، بخش‌بندی، مدیر تگ و API | ندارد | دارد |
| نصب کد | راهنما | توسط پلوتون |
| قیمت ماهانه | ۴۹۰٬۰۰۰ تومان | ۱٬۴۹۰٬۰۰۰ تومان |
| قیمت سالانه | ۴٬۹۰۰٬۰۰۰ تومان | ۱۴٬۹۰۰٬۰۰۰ تومان |

گزارش‌های هسته ماتومو در هر دو پنل هست: بازدید، صفحات، منابع، دستگاه، موقعیت، بازدید زنده، UTM و ناشناس‌سازی IP.

نقشه حرارتی، ضبط نشست، قیف و آزمون A/B جزو هسته رایگان ماتومو نیستند و در این صفحه وعده داده نشده‌اند.

## پیش‌نمایش

```bash
cd public && python3 -m http.server 8080
```

## قبل از انتشار

- قیمت، سقف بازدید و تعداد سایت را با ظرفیت واقعی سرور عوض کنید.
- ایمیل و شبکه‌های اجتماعی فوتر را با اطلاعات واقعی عوض کنید.
- فرم درخواست هنوز به سرور وصل نیست و فقط در خود صفحه پیام موفقیت نشان می‌دهد.
